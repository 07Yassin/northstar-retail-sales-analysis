# Northstar Retail — 2025 Sales Performance Analysis

## Project Overview
An end-to-end junior data analyst portfolio project analyzing 1,000 retail transaction records from 2025.

## Tools Used
- SQL (SQLite): Data cleaning, validation, and analysis
- Microsoft Excel: PivotTables, KPIs, and dashboards
- Tableau: Interactive data visualization
- PowerPoint: Business presentation and recommendations

## Key Findings
- Total revenue: $789,828.52
- Calculated profit: $183,652.15
- Profit margin: 23.25%
- Electronics was the highest-revenue product category.
- North generated the highest regional revenue.
- Retail Store was the leading sales channel by revenue.

## Data Quality
Identified a repeated order ID, one negative-revenue transaction, two missing region values, and four missing original profit values.

An unresolved $420.67 revenue discrepancy exists between the earlier Excel analysis and the restored SQL database. Financial figures are based on the restored database and should be treated as provisional pending reconciliation.

## Business Recommendations
1. Protect Electronics performance by monitoring inventory and demand.
2. Investigate opportunities for profitable Online sales growth.
3. Improve data-quality controls.
4. Reconcile financial reporting differences before final publication.

## Project Deliverables
SQL queries, SQLite database, CSV dataset, Excel dashboard, Tableau dashboard, PowerPoint presentation, and PDF report.
